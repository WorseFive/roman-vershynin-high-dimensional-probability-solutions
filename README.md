# Solutions to High-Dimensional Probability, Second Edition

This repository contains my solutions to the exercises in Roman Vershynin's High-Dimensional Probability: An Introduction with Applications in Data Science, Second Edition.

These are unofficial solutions written independently by me. They have only been checked by publisher and AI.

Although I have made every effort to ensure the correctness of the solutions, there may be mistakes or alternative approaches that are preferable. If you find an error, please feel free to open an issue or submit a pull request.


## About

I created this repository as part of my study of high-dimensional probability. I worked through the exercises throughout the book and wrote up detailed solutions, with an emphasis on providing clear derivations and explanations.

The repository currently contains solutions to all exercises in the Second Edition.

My hope is that these solutions may be useful to students and readers who are studying the book and would like to compare their own work or consult an additional explanation.

## Reference

Roman Vershynin, High-Dimensional Probability: An Introduction with Applications in Data Science, Second Edition, Cambridge University Press.

The textbook is available from the author's website and from Cambridge University Press.
